# CoreML_Example

### 📚 프로젝트 소개
위 프로젝트는 CoreML을 iOS에 직접 적용하기 위해선 어떻게 적용해야 하는지를 공부하기 위한 프로젝트이며, 음식 사진을 유추하여 해당 사진이 어떤 음식인지 판별하고 칼로리까지 표시해주도록 합니다.

### MLModel
CoreML_Example에서 사용한 mlmodel은 이미지 인식에 강점이 있는 YOLOv3.mlmodel을 사용했습니다.
